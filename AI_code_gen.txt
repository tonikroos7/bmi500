Design decisions
check_finite option: both functions accept check_finite=True (the same idea as in scipy.linalg). Pass False if NaN is meaningful in your data, such as masked voxels, and you want it to pass through.
Speed: the first version of the guards made the 1000×1000 case 18× slower. Two changes fixed that:
Plain float/int values now skip the full type check.
NaN/inf is checked once, on the final result, instead of on every element. This works because NaN and inf can never combine back into a finite number. Only when the result is non-finite does the code scan the inputs to find the bad index.
The run now takes 0.051 s, compared with 0.044 s before the guards.
NumPy input now works directly, including int64 and float32 arrays. main() now also runs six of the bad-input cases and confirms each raises the right error.
